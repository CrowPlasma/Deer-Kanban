# 🦌 Deer Kanban

Deer Kanban es una aplicación de gestión de tareas ágil, moderna y personalizable. Inspirada en la metodología Kanban, permite a los equipos y usuarios individuales organizar su trabajo en tableros, con un diseño visualmente atractivo y fondos dinámicos.

## ✨ Características Principales

* **Tableros y Listas Dinámicas:** Crea, edita y organiza tus tareas con un sistema fluido.
* **Personalización Visual (Glassmorphism):** Interfaz moderna con efecto de cristal y una galería de fondos en alta resolución (FHD).
* **Gestión de Usuarios:** Autenticación segura y gestión de miembros del equipo.
* **Filtros de Búsqueda:** Búsqueda dinámica para encontrar tareas rápidamente sin hacer scroll.
* **Papelera de Reciclaje:** Archiva y recupera tableros fácilmente.
* **Despliegue Sencillo:** Configuración lista para producción mediante contenedores.

* Orientado a personas que requieren usar Kanban con caracteristicas colaborativas o de forma individual sin tener que pasar por caja para tener ciertas funcionalidades así como puede ser posible implementarlo en empresas y maximizar la visibilidad de proyectos y avances.

* **Frontend:** React, Vite
* **Backend:** Node.js, Express
* **Base de Datos:** SQLite gestionada con Prisma ORM
* **Despliegue:** Docker y Docker Compose
